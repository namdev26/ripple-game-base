# Reusing and upgrading the package

Keep the package under source control and tag releases, for example `v0.1.0`. Games reference the tag in their UPM Git URL. Upgrade one game at a time by changing only the tag.

Each game owns its own `Assets/Settings/RippleGameAds/AdsConfiguration.asset`; do not place a real game's IDs inside the shared package repository. The resource reference generated by the menu is also project-specific.

When adding another network, create a separate UPM adapter package. It implements and registers `IAdsProviderFactory`; do not add SDK references to gameplay assemblies.
